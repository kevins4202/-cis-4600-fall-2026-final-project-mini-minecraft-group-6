# Belle Hsieh - Procedural Terrain

I implemented Perlin, FBM, and Worley noise following the lecture slides/recording using fbm(abs(Perlin)) for the jagged mountain biome and 1 - Worley for the rolling grassland hills. The two heights are blended with a LERP whose t value comes from large-grid Perlin noise passed through smoothstep(0.25, 0.75) (this is so most areas are fully one biome before transitioning). Each column is then filled with stone, dirt/grass, or stone/snow with water between y = 129 and 138. The hardest part for me was choosing noise values that made the terrain look natural. Each noise function outputs a different range so I had to measure and normalize each one before mapping it to block heights. Tuning the grid sizes took some trial and error so the terrain looked neither like static nor completely flat.

# Kevin Song - Efficient Terrain Rendering and Chunking

I built each chunk's mesh by checking the six neighbors of every filled block. I used a shared table of face corners, normals, and neighbor offsets so the same logic could generate all six sides. When a neighbor is empty, I add four vertices and two triangles for that face, translating the vertices into world coordinates using the chunk's origin. For checks outside the chunk, I use its neighbor pointers and read the opposite edge of the neighboring chunk. This removes hidden faces both inside a chunk and between chunks. I packed each vertex's position, normal, and color consecutively into one buffer, and checked the test scene's face counts against the vertex and index counts to verify the layout. Separating mesh generation from GPU uploads made it easier to check face counts and diagnose geometry issues.

For expansion, I track which 64 x 64 terrain zones already exist and create missing chunks in the nine zones around the player, matching the 192 x 192 drawing area. I saved existing chunks so they don't regenerate when we revisit them. A boundary issue was that adding terrain can hide faces in existing chunk. To handle this, I collect the new chunks and their neighbors, finish populating the terrain, and then rebuild each affected mesh once. This ensures the face checks see the completed neighboring terrain.
